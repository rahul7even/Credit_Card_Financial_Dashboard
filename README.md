# Credit_Card_Financial_Dashboard

Credit Card Weekly Status Report Dashboard using Power BI

Project Objective : The dashboard provides a comprehensive view of credit card operations, enabling stakeholders to monitor performance, track key metrics, and identify trends on a weekly basis.

Dataset : Real-time data connection to SQL database

Steps : 
•	Real-time data connection to SQL database 
•	Weekly tracking of credit card transactions and balances 
•	KPI monitoring
•	Customer segmentation and usage insights 
•	Trend analysis with dynamic filters and slicers 
•	Clean and intuitive data visualizations 

Tech Stack : 
•	Power BI – Data visualization and dashboard design 
•	SQL – Data extraction, transformation, and querying 
•	Data Modeling – Relationships, calculated columns, and measures (DAX) 

Key Impact:
Instead of static reports, stakeholders now get dynamic, drill-down insights that help in faster decision-making, risk management, and improved financial tracking.
Data isn’t just numbers—it’s a story. And with the right tools, that story becomes actionable.
